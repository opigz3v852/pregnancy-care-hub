# 啥？刚出生的宝宝也会低血糖吗？

> 更新时间：2026-09-17 (UTC+8)

傍晚时分的产科病房洋溢着温馨与欢乐。护士站突然传来了一位宝爸的呼叫声：“护士，护士，快帮我看看宝宝，我觉得他好像有点不对劲。”护士来到床边，仔细地观察宝宝，宝宝面色苍白，哭声声音弱，反应差，额头上有汗珠，护士立即汇报了医生，遵医嘱监测血糖，血糖值只有1.4mmol/L，经过医务人员的紧急处理，最后宝宝的血糖值升到了2.8mmol/L，宝宝脸色转为红润，哭声响亮，转危为安。

**什么是新生儿低血糖？**

新生儿经历了从宫内到宫外的环境变化，其血糖水平较易产生较大的波动。宝宝出生后1-4小时内因暂时性的自身胰岛素水平偏高等生理性变化，若未及时建立有效喂养，容易发生过度期低血糖。

新生儿低血糖是新生儿的血糖水平低于机体需要的血糖浓度。我国新生儿低血糖的诊断标准为不论新生儿胎龄、日龄、或出生体重多少，血糖值<2.2mmol/L即可诊断为新生儿低血糖，但是在临床上血糖值<2.6mmol/L就要引起足够的重视，需要行临床干预。

**新生儿低血糖的危害有哪些？**

持续反复发作新生儿低血糖可引起严重的中枢神经损害，出现急性和慢性脑功能障碍，并可在远期出现运动发育落后、视觉障碍、学习和行为困难、小头畸形及远期癫痫发作，甚至智力低下、脑瘫等神经系统后遗症。

**哪些宝宝容易发生低血糖？**

**母亲因素：**

1. 母亲本身患有糖尿病的，或者在怀孕期间患有糖尿病的。

2. 母亲怀孕期间患有高血压的。

3. 母亲血型不合造成的溶血高危情形。

4. 母亲有代谢性疾病或内分泌疾病史。

**新生儿因素：**

1.特殊宝宝：早产儿（胎龄小于37周），巨大儿(出生体重>4000g)，足月小样儿（足月出生体重低于2500g），双胎。

2.没有及时喂养或者延迟喂养者。

3.低体温，产时缺氧等

    以上情况属于特别需要注意的，如果即使没有出现这些情况，宝爸宝妈们仍然要密切注意宝宝的情况，如果有反应差，惊厥，拒乳，面色苍白等。

**新生儿低血糖的临床表现**

新生儿低血糖大部分是没有明显症状。

有症状时可以有以下表现：

1. 出汗、脸色苍白。

2. 躁动、震颤、过强的惊跳反射。

3. 吸吮差或者拒绝喂食、呕吐。

4. 高频的哭，哭声尖或者哭声弱。

5. 癫痫或肌痉挛

6. 淡漠、嗜睡、疲软、肌张力低下。

7. 昏迷、发绀。

8. 呼吸暂停或者不规则；呼吸急促

9. 低体温、体温不稳定。

当宝爸宝妈发现有以上症状时需要及时告知医护人员。

**新生儿低血糖该如何预防？**

1. 产后30分钟内即可开始母婴皮肤接触、早吸吮、早开奶。

2. 鼓励母乳喂养，符合补充喂养指征的遵医嘱添加配方奶。

3. 加强喂养，在按需喂养的原则下，新生儿喂养24小时不少于8-12次。

4. 注意保暖，保持体温在36.5℃-37.5℃。

5. 减少哭闹：哭闹会迅速消耗储备糖原。

6. 根据观察宝宝的精神状况、面色、哭声、呼吸、排便排尿和睡眠情况早期判断是否出现新生儿低血糖，如有异常及时呼叫医务人员。

7. 做好血糖监测：宝妈孕期监测血糖，控制血糖；配合医护人员，监测新生儿血糖，尤其是高危儿。
