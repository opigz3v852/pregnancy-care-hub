# 孕妇怎么补血

> 更新时间：2026-09-11 (UTC+8)

孕妇贫血的表现

除一般贫血症状外，有以下特点：

1、多发生于妊娠晚期，约50%发生于孕31周后，其余发生于产褥期。常见于30岁左右，经产妇多于初产妇，多胎多于单胎。25%病人在下次妊娠时易再发。

2、起病急，贫血多为中度或重度。多表现为头昏、疲乏无力、全身水肿、心悸、气短、皮肤黏膜苍白、腹泻、舌炎、乳头萎缩等。低热、脾肿大、表情淡漠也常见。

3、消化道症状明显，部分患者有恶心、食欲不振、呕吐及腹泻，可伴有舌唇疼痛，急性发作时舌尖及舌边缘疼痛明显，舌面呈鲜红色，所谓“牛肉样舌”。可出现血性小泡或浅小溃疡，进一步舌乳头萎缩成“光舌”。

4、因维生素B12缺乏可致周围神经炎，表现为乏力、手足麻木、感觉障碍、行走困难等周围神经炎及亚急性或慢性脊髓后束侧束联合病变等神经系统症状。

5、对妊娠的影响：如及时处理，预后较好。如不及时处理，重症者可引起流产、早产、胎盘早剥、胎儿生长受限、死胎等并发症，常伴有呕吐、水肿、高血压、蛋白尿。在产褥期发生贫血的，多在产后第1周，因在原有缺乏叶酸的基础上，哺乳加重叶酸的缺乏，如不及时补充则常诱发贫血症状。
 
孕妇补血的好处

1、预防孕妇妊娠期贫血

血液是身体的运输工具，遍布全身，将氧气、营养带到全身，所以人不能缺血。铁是制造血红素的主要成分，孕妇需吸收更多铁质来制造血红蛋白。由于储存在孕妇体内的铁质被胎儿所吸收，因此孕妇需要不断摄取铁质，否则容易患上贫血，更会阻碍胎儿发育。

2、预防孕妇产后贫血

孕妇需要多多补血，来预防孕妇贫血引起的疲倦、晕眩、心悸气喘，以及觉得手脚冰冷。孕妇在分娩时会流失不少血液，若孕妇在产前不多摄取铁质、补充血液，产后便容易患上贫血。

3、催生乳汁

接下来的哺乳期，产妇更需要补血，催生乳汁。
 
孕妇补血的食谱

炒鸡胗肝粉

材料：米粉面条、鸡胗肝、葱头、丝瓜、花生油、盐、白糖、湿淀粉、葱花、料酒、鲜汤少许。

做法：

1、鸡胗肝切片，加入盐、白糖、湿淀粉、料酒，搅拌均匀。丝瓜刮皮洗干净，切片；米粉面条用开水烫熟，沥干水分。

2、锅里放入油烧到五六成热，倒入鸡胗肝片，用筷子划开，至七八成熟，捞出。原锅倒入米粉面条和盐，炒至柔软，起锅入盘。

3、另用一锅上火，烧热油倒入丝瓜片，葱头条炒到半熟，放入胗肝片，加盐、白糖和鲜汤，煮开后再炒片刻，撒上葱花炒匀，盛出覆盖在米粉面条上即成。

猪肝粥

材料：大米、猪肝、水、花生油、盐、味精、料酒、淀粉、葱花、姜末。

做法：

1、大米洗干净。猪肝切成薄片，加入淀粉、葱花、姜末、料酒和少许盐，抓拌均匀，腌制一会。

2、锅里加入油烧热到五六成热，放如猪肝片，用筷子划开，约1分钟，至猪肝半熟，捞出控油。

3、另用一锅倒入水烧开，加入大米，烧开后改用小火熬煮约30分钟，放入猪肝片，用小火煮10-20分钟，直到大米全部开花，肝片酥熟，汤汁变稠，加上味精和盐调味即可。
 
孕妇补血补多少好

每个女人在怀孕期间身体都会发生很大的变化，很多时候营养常常都跟不上，特别是很多孕妇会血虚，孕妇正确服用补血保健品，能够起到预防贫血、让胎儿健康发育的作用。但如果错误服用补血保健品，却会被宝宝和孕妇都带来危害。那么孕妇补血补多少好呢？

孕妇补血要遵循“小量、长期”的原则，在孕早期要慎用阿胶保健品，这里所说的慎用不是不用而是要注意服用的剂量，孕妇是可以吃阿胶的，但由于阿胶有活血的作用，一般孕期前三个月最好不要吃，吃的话宜少量，每日3-5克；但到了孕5-6个月时孕妇容易贫血，每日可服用-9克。

所以孕妇在补血的时候要遵循“小量、长期”的原则，严格按医嘱服药，切勿自作主张加大服药剂量，以免铁中毒；也绝不能一次大剂量，否则易致急性铁中毒。

孕妇应饭后服用保健品：饭后服用保健品，以减轻药物对胃肠道的刺激而引起的恶心呕吐。同时服用维生素C或果汁，因酸性环境有利于铁的吸收。

铁剂要避免和钙类食品合用含钙类食品（如豆腐）和高磷酸盐食品（如牛奶）等，与铁剂能络合而生成沉淀，故应避免合用。
 
孕妇补血的注意事项

孕妇补血是非常重要，对母婴都有好处。补血后，孕妇的血液量大幅增多，便能供应更多氧气给胎儿，令胎儿更好地发育，还能有效预防孕妇贫血。但孕妇在补血的时候，有一些事项和误区需要额外注意和避免，本专区为孕妈们详细介绍。

1、禁忌食物不要吃

孕妇补血其实就是补铁，有些物质会影响身体对铁质的吸收。下面这些食物，孕妇在补铁的时候不能同时进食。

（1）单宁酸：茶、咖啡与红酒等

由于单宁酸会与铁质结合后沉淀，阻碍了身体对铁质的吸收，所以常见富含单宁酸的饮食来源，如茶、咖啡与红酒等，都不适宜与高铁食材搭配食用。

（2）草酸：巧克力、茶与花生

巧克力、茶与花生等是常见富含草酸的食物，但由于草酸本身会与铁质作用而相互抵销，导致真正进入体内的铁质较少，所以不建议在吃高铁食材时一同食用。

（3）磷酸：可乐等碳酸饮料

一般来说，磷酸会阻碍铁质的吸收，而国人最常接触到的磷酸多半来自于碳酸饮料中(如：可乐)，举例来说，若妈咪们在吃富含高铁质的牛排时，就不该搭配饮用可乐，才可确保铁质的正确吸收。

（4）植酸：麦片、燕麦与荞麦

植酸最主要存在于麦片、燕麦与荞麦等谷物类食物，且由于植酸会与铁质结合，降低人体对于铁质的吸收，所以妈咪们要避免同时使用。

2、要在医生指导下补血

孕妇如需补血，应在医生指导下进行。如果盲目补铁，只会导致铁中毒，严重影响胎儿和孕妇的身体健康。孕妇补血更应注重营养的全面补充，采用安全有效的补血方法，比如补充具有黄芪、当归等成份的补血产品。实践证明，通过调整和改善孕妇的不合理的膳食结构，保证供给充足的热能和蛋白质，提供充分的铁、维生素C，就能有效地预防和纠正孕妇贫血，其效果优于药物治疗。

3、多使用铁质炊具

做菜时尽量使用铁锅、铁铲，这些传统的炊具在烹制食物时会产生一些小碎铁屑溶解于食物中，形成可溶性铁盐，容易让肠道吸收铁。

4、饭后服用补铁剂

应在饭后服药，避免空腹服药，以减轻药物对胃肠道的刺激而引起的恶心呕吐。同时服用维生素C或果汁，因酸性环境有利于铁的吸收。口服铁剂时应将药物放在舌面上，直接用水冲饮下肚，不要咀嚼药物，以免染黑牙齿，影响美容。
